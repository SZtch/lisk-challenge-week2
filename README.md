# ⚡ Lisk Challenge Week 2  
**Smart Contract Deployment & Block Explorer**

> A decentralized dApp built for the **LiskSEA Speedrun Week 2**, focusing on deploying, verifying, and exploring smart contracts on **Lisk Sepolia** using the Scaffold-ETH 2 stack.

🔗 **Live App:** [https://lisk-challenge-week2.vercel.app](https://lisk-challenge-week2.vercel.app)

---

## 🧱 Overview

This project demonstrates:
- ✅ Smart contract deployment on **Lisk Sepolia**
- ✅ On-chain transaction explorer with real-time verification
- ✅ Wallet connection (MetaMask, WalletConnect, Coinbase, Brave, Rainbow)
- ✅ Local tx history tracking
- ✅ Full build + deploy pipeline on **Vercel**

Built with **Next.js 14**, **TypeScript**, **TailwindCSS**, and **RainbowKit**.

---

## 🛠️ Tech Stack

| Layer | Stack |
|-------|-------|
| **Frontend** | Next.js 14, TypeScript, TailwindCSS, DaisyUI |
| **Blockchain** | Lisk Sepolia (EVM compatible) |
| **Wallets** | RainbowKit, Wagmi, WalletConnect v2 |
| **RPC Provider** | Alchemy |
| **Hosting** | Vercel |
| **Template Base** | Scaffold-ETH-2 |
